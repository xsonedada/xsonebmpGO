## 🚀 Возможности

### Для покупателей
- 🔍 **Поиск услуг** — фильтрация по играм, цене, рейтингу
- 🛡️ **Эскроу-защита** — деньги замораживаются до подтверждения выполнения
- ⭐ **Рейтинг продавцов** — выбирайте лучших по отзывам
- 💬 **Чат с продавцом** — обсуждайте детали заказа

### Для продавцов
- 💰 **Удобная витрина** — добавляйте свои услуги за пару кликов
- 📊 **PRO-аналитика** — отслеживайте продажи, доход, конверсию
- 🏆 **Система достижений** — получайте бейджи и повышайте уровень
- 👑 **PRO-подписка** — сниженная комиссия (2%), приоритет в поиске

### Админ-панель
- 👥 Управление пользователями
- 📦 Мониторинг заказов
- 📈 Статистика и графики
- 🎫 Тикеты поддержки и диспуты

## 🔐 Безопасность

- ✅ Защита от XSS и SQL-инъекций
- ✅ CSRF-токены на всех формах
- ✅ Rate limiting (ограничение попыток входа)
- ✅ Валидация email (MX-запись, регулярные выражения)
- ✅ Honeypot-поля для защиты от ботов
- ✅ Эскроу-система для безопасных сделок
- ✅ Content Security Policy (CSP)

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/xsonedada/xsonebmp.git
cd xsonebmp

# Настройте базу данных (создайте БД xsonebmp)
psql -U postgres -c "CREATE DATABASE xsonebmp;"

# Настройте переменные окружения (создайте .env)
cp .env.example .env
# Отредактируйте .env: укажите данные БД, секретный ключ

# Запустите приложение
go run main.go 
```
